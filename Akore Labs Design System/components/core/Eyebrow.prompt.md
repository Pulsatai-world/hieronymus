Wide-tracked uppercase kicker that labels a section — Akore's signature type device, mirroring the wordmark's letter-spacing. Place directly above a heading.

```jsx
<Eyebrow marker="tick">Generative Engine Optimization</Eyebrow>
<h2>Get found inside the answer.</h2>
```

`marker`: `tick` (violet rule), `dot` (emerald dot), or `none`. Set `onDark` on dark backgrounds.
