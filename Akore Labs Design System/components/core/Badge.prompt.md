Small pill for tags, statuses, and metadata.

```jsx
<Badge tone="emerald" dot>Live audit</Badge>
<Badge tone="violet">GEO</Badge>
<Badge tone="outline">Case study</Badge>
```

Tones: `violet`, `emerald`, `neutral`, `solid`, `outline`, `outline-dark` (for dark backgrounds). Sizes `sm` / `md`. `dot` adds a leading status dot.
