Surface container with Akore's calm elevation — 16px radius, hairline border, low, cool-tinted shadow.

```jsx
<Card variant="raised" interactive padding="28px">
  <Eyebrow>GEO Audit</Eyebrow>
  <h3>Answer-engine visibility score</h3>
</Card>
```

Variants: `default`, `raised`, `subtle` (sunken gray), `inverse` (dark), `brand` (violet gradient). `interactive` adds hover lift. Set `padding` as a CSS shorthand string.
