Big display metric for results and proof points — headline figure in the display font with a colored accent.

```jsx
<Stat value="3.4×" label="Answer-engine mentions" accent="emerald"
      caption="Average lift across GEO engagements in 90 days." />
```

`accent`: `violet` / `emerald` / `ink`. Set `onDark` on dark sections; `align` left or center.
