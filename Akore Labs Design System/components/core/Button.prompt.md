Fully-rounded pill button for Akore Labs — use for any click action; `primary` (violet) for the main CTA, `accent` (emerald) sparingly for one hero action.

```jsx
<Button variant="primary" size="lg" iconRight={<Icon name="arrow-right" size={18} />}>
  Book an audit
</Button>
```

Variants: `primary` (violet fill), `accent` (emerald fill), `secondary` (hairline outline on white), `ghost` (violet text, tinted hover), `inverse` (translucent, for dark sections). Sizes: `sm` / `md` / `lg`. Supports `iconLeft` / `iconRight`, `fullWidth`, `disabled`.
