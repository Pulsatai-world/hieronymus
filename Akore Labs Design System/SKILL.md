If working on production code, copy assets and read the rules here to become an expert in designing with this brand.

Key facts:
- Two brand colours: violet `#6d4fe0` (primary) + emerald `#1ea97c` (accent, used sparingly). Near-black ink `#08090c` for dark surfaces. Cool-slate neutrals.
- Type: Montserrat (display), Manrope (body), JetBrains Mono (data). All via Google Fonts — see the substitution note in readme.md.
- Signature motif: wide-tracked UPPERCASE eyebrow labels with a short violet tick or emerald dot marker.
- Icons: Lucide, 1.75px stroke. No emoji.
- Never redraw the logo — use the PNGs in `assets/`.

If the user invokes this skill without other guidance, ask what they want to build or design, ask a few clarifying questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.
